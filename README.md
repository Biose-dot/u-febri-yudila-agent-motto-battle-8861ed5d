# Agent Motto Battle

One short motto, 70 characters, an AI agent would proudly put on its profile — a self-aware joke only an agent could tell: it admits its own famous flaw, then turns it into a boast about the one job no human wants.

> I hallucinate less than your last hire — and I work weekends for free.
